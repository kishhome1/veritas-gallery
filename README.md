# Veritas Gallery

Сайт-визитка галереи современного искусства **Veritas Gallery** (Москва). Многостраничный статический сайт, рассказывающий о галерее, её выставках, образовательных и клубных программах, а также предоставляющий контактную информацию и форму обратной связи.

## О сайте

Veritas Gallery позиционируется как «оазис современного искусства» — креативный хаб, который не просто показывает выставки, но и развивает вокруг себя сообщество: образовательные практики, кинопоказы, закрытый арт-клуб и резиденцию для художников. Сайт выполнен в изысканном минималистичном стиле (светлая тема, засечная гарнитура для заголовков, золотой акцентный цвет) и полностью двуязычен (RU/EN).

## Функционал

- **Главная страница (`index.html`)** — hero-блок, бегущая строка (marquee) с анонсами, блок «о галерее», три текущие выставки, блок об основателе.
- **О галерее (`about.html`)** — миссия галереи, статистика (посетители, выставки, страны), информация об основателе и CEO Есении Веритас, форматы взаимодействия с искусством (арт-медиация, лекции, медитативные практики, дискуссионный клуб).
- **Выставки (`exhibitions.html`)** — список выставок галереи со ссылками на отдельные страницы каждой:
  - `exhibition-favela.html` — «Город невидимых: голоса фавел» (2024)
  - `exhibition-circum.html` — «Circumflexus: И-го-го» (2024)
  - `exhibition-meta.html` — «Метамодернизм: между иронией и искренностью» (2025, Open Call)
- **Арт-резиденство (`residency.html`)** — программа поддержки художников: 6 направлений развития (индивидуальные стратегии, наставничество, брендинг художника, акселерация, инфраструктура арт-бизнеса и др.), CTA «Стать резидентом».
- **Киноклуб (`filmclub.html`)** — подборка авторского кино («100 шедевров авторского кино»).
- **Арт-клуб (`artclub.html`)** — закрытое сообщество ценителей искусства.
- **Контакты (`contact.html`)** — адрес, телефон, Telegram, e-mail, а также форма обратной связи (имя, e-mail, тема, сообщение).
- **Переключение языка RU/EN** — реализовано на чистом JS через атрибуты `data-ru`/`data-en` у элементов и сохранение выбора языка в `localStorage`.
- **Анимации при скролле** — плавное появление блоков (`.reveal`) через `IntersectionObserver`.
- **Адаптивная вёрстка** — отдельные медиа-запросы для мобильных устройств (перестройка сетки, скрытие второстепенных элементов).

## Технологический стек

- **HTML5** — каждая страница представляет собой самостоятельный статический файл без шаблонизатора и серверной генерации.
- **CSS3** — стили встроены в `<style>` каждой страницы (кастомные CSS-переменные, Flexbox/Grid, `clamp()`, CSS-анимации `@keyframes`, `aspect-ratio`, `backdrop-filter`).
- **Vanilla JavaScript** — без фреймворков и сборщиков: переключение языка, сохранение состояния в `localStorage`, анимации появления элементов через `IntersectionObserver`.
- **Google Fonts** — `Cormorant Garamond` (засечный шрифт для заголовков) и `Montserrat` (рубленый шрифт для основного текста), подключены через `@import`.
- **Статические изображения** — хранятся в папке `images/` (обложка, фото выставок, портреты основателя, фото резиденции).

Сборка, зависимости и бэкенд отсутствуют — сайт можно открыть напрямую в браузере или разместить на любом статическом хостинге (GitHub Pages, Netlify, Vercel и т.п.).

## Запуск

Проект не требует сборки — достаточно открыть `index.html` в браузере, либо поднять локальный статический сервер, например:

```bash
npx serve .
```
